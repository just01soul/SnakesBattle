# 🐍 SnakesBattle

Браузерная игра «Змейка» на Vue 3 + TypeScript. Начинается как классическая одиночная игра, но архитектурно закладывается под будущий режим «битвы змеек» на одном поле.

## 📖 О проекте

**SnakesBattle** — пет-проект, в котором классическая механика «Змейки» реализуется на современном стеке Vue 3 с прицелом на расширение до соревновательного режима.

Текущая версия (v0.1) — одиночная игра: игрок вводит ник, управляет змейкой стрелками, собирает еду, набирает очки. Рекорд сохраняется в рамках сессии.

Дальнейшее развитие — режим на двоих: две змейки на одном поле, у каждой свой счёт, по окончании матча определяется победитель. Именно под этот сценарий проектируется структура состояния (Pinia store) и игровая логика (чистые функции, принимающие состояние змейки параметром).

Проект пишется для себя: без дедлайнов, без заказчиков, с возможностью пробовать новые подходы и доводить детали до состояния, которое нравится лично мне.

## 🏗️ Архитектура

Проект разделён на три слоя, чтобы игровую логику можно было тестировать и переиспользовать независимо от Vue:

```
src/
├── assets/
│   └── global.css          # Tailwind + палитра игры (@theme)
├── components/             # Презентационные компоненты
│   ├── NicknameScreen.vue  # Ввод ника перед стартом
│   ├── GameControls.vue    # Панель счёта и рекорда
│   ├── GameBoard.vue       # Игровое поле (CSS Grid)
│   └── GameOverScreen.vue  # Экран результатов
├── game/                   # Игровой движок (без Vue-специфики)
│   ├── types.ts            # Point, Direction, GameState
│   ├── snake.ts            # Чистые функции: createInitialState, moveSnake, ...
│   └── useGameLoop.ts      # Vue-обёртка: таймер, клавиши, связка со стором
├── stores/
│   └── gameStore.ts        # Pinia Setup Store — единый источник правды
├── App.vue                 # Переключение экранов
└── main.ts                 # Точка входа: createApp + Pinia + global.css
```

**Принципы:**

- **Чистая логика отдельно от Vue.** Функции в `game/snake.ts` не используют `ref`/`computed` — их легко покрыть тестами и вызвать дважды для двух змеек.
- **Единый источник правды.** Счёт, статус игры, позиция змейки живут в `gameStore`, компоненты читают их через `storeToRefs`.
- **Тонкая Vue-обёртка.** `useGameLoop` только оркестрирует: `setInterval`, обработка `keydown`, вызов чистых функций и запись результата в стор.
- **Задел под вторую змейку.** Типы и функции уже принимают состояние параметром — добавление второй змейки не потребует переписывания движка.

## 🚀 Быстрый старт

### Требования

- Node.js `^22.18.0` или `>=24.12.0`
- npm (или pnpm/yarn — по вкусу)

### Установка

```sh
npm install
```

### Запуск в режиме разработки

```sh
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) — увидите экран ввода ника.

### Сборка

```sh
npm run build
```

Скрипт выполняет `vue-tsc --build` (проверка типов) и `vite build` (минификация).

### Проверка типов отдельно

```sh
npm run type-check
```

### Линтинг и форматирование

```sh
npm run lint      # oxlint + eslint с автофиксом
npm run format    # prettier для src/
```

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| `↑` `↓` `←` `→` | Смена направления змейки |
| `Space` | Пауза / продолжение |
| `Enter` | Подтверждение ника на стартовом экране |

## 💡 Идеи на подумать

- Мультиплеер по сети (WebSocket) — превращает локальную «битву» в полноценный онлайн-режим.
- Ежедневные испытания — фиксированный сид еды и препятствий для всех игроков.
- Режим «на время» — кто наберёт больше очков за 60 секунд.
- Достижения — «съешь 10 яблок за игру», «пройди без столкновений» и т.п.
